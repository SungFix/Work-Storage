# Work Storage

Cofre pessoal para armazenar prompts, logins, senhas, notas, arquivos e outras informações privadas com organização, pesquisa e segurança.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase / PostgreSQL

## Desenvolvimento local

```bash
npm install
npm run dev
```

Copie `.env.example` para `.env.local` quando conectar o Supabase.

## Publicação

O projeto inclui um workflow para GitHub Pages. A versão publicada atualmente é uma demonstração visual; autenticação e dados reais serão conectados ao Supabase nas próximas etapas.
